# Пивной совет

Приложение для Сани, Димана и Тёмы: план сходки (кто идёт, где, кто что берёт, еда, пиво, политика, карты, прогулка), календарь предложений с голосованием и фидбек со звёздами.

APK собирается GitHub Actions при каждом пуше в `main` и появляется в Releases.
Данные хранятся на телефоне (без сервера).
